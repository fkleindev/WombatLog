Custom sounds for WombatLog
===========================

1. Put your .ogg or .mp3 files into this folder.
2. Restart the game. It only sees new files after a restart, /reload is not enough.
3. Open the WombatLog settings, go to "Custom sounds" and add each file by its name
   (for example "boom.ogg", or just "boom" for an .ogg file).

Added sounds show up as "Custom: ..." in every sound list.

Updating WombatLog can replace the addon folder, so keep a copy of your sounds.
